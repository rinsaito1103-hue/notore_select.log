# 農トレ 比較実験用（ログあり群 / ログなし群）

- `a/` … ログ機能あり版（Supabase の log_group = "log"）
- `b/` … ログ機能なし版（Supabase の log_group = "nolog"）
- 管理者画面: `a/host.html`（`b/host.html` も同じ内容）
- 公開前に `supabase/add_log_group_column.sql` を Supabase の SQL Editor で実行すること

両群とも同じルームIDで実施する。

土地の一斉発表の流れ:
1. 学生がスタートを押すと参加登録だけが行われ、「土地の発表を待っています」画面で待機する
2. 管理者画面（host.html）の「🎲 土地の一斉発表」に参加チームが受付順に表示される
3. 全チームがそろったら「土地を一斉発表する」を押す → 全員の画面に土地が表示される
4. あとから来たチームがいたら、もう一度押すとそのチームにも配られる（配り済みの土地は変わらない）

土地の決め方（受付順に全チーム分を計算）: 自分の群で最も少ない土地 → 同数ならもう一方の群で多い土地
→ それでも同数ならルームIDごとに決まる順番。各群で6種類が均等になり、両群の構成もそろう。
チーム名は両群を通して重複させないこと。
